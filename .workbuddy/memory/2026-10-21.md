# 2026-10-21

## 修复 conferenceroom-front 依赖安装失败问题

- 症状：`npm run serve` / `npm run build` 报 `'vue-cli-service' 不是内部或外部命令`；`npm i` 报 `CERT_HAS_EXPIRED`。
- 根因链：
  1. 原始 `package-lock.json` 是老版淘宝镜像（registry.npm.taobao.org，证书已过期）生成的，导致任何安装都失败。
  2. 中断的安装留下了残缺的 lockfile（缺 chalk 等传递依赖条目），后续 `npm i` 无法自愈，报 `Cannot find module 'chalk'`。
- 修复：备份旧 lockfile 为 `package-lock.json.bak`，删除 lockfile + node_modules，用 `npm install --registry=https://registry.npmmirror.com` 全新安装（1326 包）。
- 验证：`npm run build` 完整通过，dist 目录正常生成；Node 22 + Vue CLI 4（webpack 4）未触发 OpenSSL md4 报错，无需 `--openssl-legacy-provider`。
- 注意：沙箱内运行 `npm run serve` 会被安全策略拦截（vue-cli 调 wmic.exe 检测端口），需在用户自己的终端运行 serve。
- 项目环境备注：机器装有腾讯电脑管家 + 奇安信天擎，偶发 EPERM 文件锁；node 22（用户终端 22.22.1 / 沙箱 22.22.2），npm 9.6.6，开发端口 8881，未使用 scss。
